# Bundled fonts

Noto Sans SC and Noto Sans JP from Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notosansjp

Fonts are distributed under the SIL Open Font License 1.1, reproduced in the
accompanying OFL files. Converted losslessly from TTF containers to WOFF2 using
fontTools. These fonts make the added UI languages work offline regardless of
Windows supplemental fonts. No fonts are downloaded by the application.
